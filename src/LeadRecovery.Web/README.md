# LeadRecovery.Web

This path is reserved by Milestone 0 so the deployable layout is explicit.

The Next.js application is initialized in Milestone 2 together with same-origin
authentication and the dashboard shell. Do not add frontend product code before
that milestone.

Approved frontend baseline:

- Node.js 24.17.0 LTS;
- pnpm 11.10.0;
- Next.js 16.2.10;
- React 19.2.7;
- TypeScript 6.0.3.
